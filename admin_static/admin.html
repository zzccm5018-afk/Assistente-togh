Atenção: o endpoint /ingest do main.py indexa apenas texto — não existe OCR automático de imagem no backend. Para arquivos .txt/.md o texto é lido direto no navegador. Para imagens, anexe o arquivo (fica só como referência visual/metadado) e cole manualmente o texto que deve ser indexado.
